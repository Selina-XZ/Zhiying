# 知应

知应是社区养老服务的数字人助手：帮助老人听明白事情、做好选择，也帮助工作人员把事项讲清楚、把老人的需求收上来。

## 老人可以这样用

### 听数字人讲事项

打开知应后，首页先看到数字人。工作人员下达的事项，数字人会用**声音、大字字幕和图片**一起讲清楚：正文、时间、地点，以及您可以怎么选择。

### 把自己的事告诉工作人员

在“我想告诉工作人员”里，选择一类事情再填写：

- **身体不舒服**：按您的原话转交工作人员。知应不会诊断病情，也不会给您用药建议。
- **请工作人员帮忙**：生成一条待办，等工作人员来处理。
- **其他事情**：把想说的话清楚提交。

### 做出选择、设置提醒

数字人讲完后，才会出现大按钮，让您**慢慢选、慢慢确认**：

- 可以先“重听”“换一种说法”，也可以“稍后决定”“拒绝”或“请工作人员帮助”。
- 只有点击确认、并且保存成功，页面才会显示“已保存”。这不等于事情已经办完。
- 事项允许提醒时，您可以选择提前多久提醒；保存成功后页面会显示准确的提醒时间。

### 和数字人说话

点“开始语音交流”，就可以和知应连续对话；也可以**随时开口打断它**。说话内容只用来回答您，不会保存录音或对话。不想说了，点“结束语音交流”即可。

## 工作人员可以这样用

### 发布三类内容

- **事项与提醒**：填写正文、时间、地点、图片，设置 1～3 个老人可选的大按钮，并决定是否允许提醒。
- **宣传讲解**：填写宣传正文和可选图片。
- **自定义内容**：发布其他需要老人了解的内容。

只有“事项与提醒”需要时间、地点、选项和提醒；其余两类只设置正文和图片。

### 配图

每条下达内容都可以配一张图：

- 上传一张审核过的图片；或
- 让系统生成一张 AI 辅助图（带水印，**必须核对后再发布**）。

也可以不配图，知应会按已填写的正文、时间、地点自动排版一张信息图。

### 回复老人

在对应事项卡里直接展开编辑器，写下反馈并保存。回复只表示已经反馈，不表示求助或代办已经办完。

### 查看老人端运行状况

工作人员端顶部可以看到老人页面是否打开、数字人是否连接、是否正在播报、麦克风是否在聆听、当前事项和最近动作。老人页面关闭或状态过期后，会如实显示“当前未在线”。

## 几条要记住的原则

- **未回应不算同意**；确认收到不等于接受安排；选择或提醒保存成功，也不等于事情已经办完。
- 身体不舒服时，只按老人原话转交工作人员，**不自动诊断、不提供用药建议**。
- 提醒是真实保存的任务，不是口头说一句“会提醒”；页面关闭或设备休眠时，网页不能像系统闹钟一样发声。
- 当前是演示原型，只使用虚构数据，未接真实老人信息，不能用于公开部署。

## 运行说明（给部署和测试人员）

### 环境要求

- Python 3.9 或更高（本机验证为 3.12）。
- 项目只使用 Python 标准库和原生网页，**无需安装第三方依赖**。

### 启动

```powershell
python server.py
```

浏览器访问 http://127.0.0.1:8765 。

首次运行会自动创建本地数据 `data/app.db`；页面刷新后数据保留。关闭服务使用 `Ctrl+C`。

### 本机连接魔珐数字人

1. 启动服务，打开 http://127.0.0.1:8765 。
2. 在首页底部展开“仅本机测试人员：连接或断开真实数字人”。
3. 从魔珐控制台复制当前驱动应用的 App ID 和 App Secret，只粘贴到本地页面，不要发送到聊天或截图。
4. 勾选风险确认并点击“连接”，等待资源加载到 100%。
5. 页面会先显示“会话已连接，等待 SDK 渲染”；收到渲染回调后，请实际核对背景和人物是否同时可见——只有声音或背景不算通过。
6. 测试结束后展开设置点击“断开数字人”，再关闭页面。

凭据只进入当前页面内存和魔珐 SDK，不写入源码、`.env`、数据库、日志或浏览器存储，禁止公开部署。

### 配置豆包（可选）

豆包只用于服务端生成辅助图片和语音对话回答。Key 不写入 `.env`、源码或浏览器存储，只在启动服务的同一个 PowerShell 进程里临时设置：

```powershell
$env:ARK_API_KEY='仅在本机终端输入'
$env:ARK_IMAGE_MODEL='doubao-seedream-5-0-flash-260915'
$env:ARK_TEXT_MODEL='doubao-seed-2-1-lite-260915'
python server.py
```

### 测试

```powershell
python -m unittest discover -s tests -v
```

### 未配置外部服务时能使用哪些功能

- **不连接魔珐、也不配置豆包**，核心业务仍可用：工作人员三类发布（人工上传图片或自动信息图）、回复老人、查看运行状态；老人三类上传、查看事项、大按钮选择、设置提醒、查看工作人员回复。
- **需要豆包 Key** 的功能：AI 辅助配图、语音对话回答。
- **需要魔珐凭据** 的功能：数字人语音播报、口型和语音交流。
